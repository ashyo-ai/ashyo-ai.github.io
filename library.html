Library

The Library is where your reusable pieces live: connection and sampler presets, system prompts, context and instruct templates, personas, characters, lore books and regex scripts. Settings picks from the Library for each chat; the Library is where you make, edit, import and export the items themselves.

Tabs

Type /library to open it. The pane on the left lists ten tabs, one per kind of item:

  • Connection presets, the route to a model. See below and Connections.
  • Sampler presets (chat) and Sampler presets (text), one set per protocol. See below and Samplers.
  • System prompts, the instructions that open the prompt. See below.
  • Context templates, the order and framing of the prompt's parts. See below.
  • Instruct templates, the tokens a text-completions model expects around each turn. See below.
  • Personas and Characters, who talks. See below and Personas and characters.
  • Lore books, facts that join the prompt when the chat touches them. See below and Lore books.
  • Regex scripts, find-and-replace rules that run on messages. See below and Regex scripts.

Each tab opens with an item picker row labeled by the kind, such as Character, showing the item you are looking at. Enter on it lists every item of that kind. Below it come the item's fields. The item you chose stays chosen while you work, even as the screen refreshes. A tab with nothing in it says "No characters" (or whichever kind) and offers a New item row.

Connection preset items show their Route (the Provider, which may be None, and the Protocol) followed by the provider's field groups, with unset fields showing the provider's defaults. Sampler preset items show their groups with each sampler's limits.

If one item fails to load, Ashyo reports it and the other tabs still load. Moving around and editing rows works exactly as in Settings; see Moving around and editing rows.

Heads up

Templates are edited in place. A change to a context or instruct template applies to every chat that uses it, the moment you make it. There are no overrides for templates and no Save step. To try something without touching a template other chats rely on, duplicate it first with Save as in Settings, or make a New one here.

Actions

Press Tab on the item picker row to see what you can do with the kind and the item:

  • New. Asks for a name in a prompt titled "New character", "New lore book" and so on, then creates an item with default values and shows it.
  • Import. Opens the file dialog to bring in a file: an Ashyo item file, a character card, a World Info book or a SillyTavern preset. The imported item is revealed in the Library with a notice about anything that was left out. See Import and export.
  • Export. Writes the item as a JSON file through the file dialog and confirms with "Exported to path." A connection preset exports without its account and without fields its provider does not use. See Ashyo item files.
  • Rename. Asks for the new name. Everything that refers to the item follows; see Names.
  • Delete. Asks "Delete this item?" The default answer is Keep.

An empty tab offers only New and Import. Individual entries inside an item, such as a greeting or a lore entry, have their own actions on their own rows; see Lists of entries.

Nothing ships for the other kinds: there are no sampler presets, connection presets, lore books or regex scripts until you make or import them. Providers are built into Ashyo and are not Library items.

Names

Every item has a name. Names are trimmed, required and must be unique within their kind; an empty name is refused with "Name is required." and a taken one with "Name already exists." Lists sort by name without regard to case. A new item starts from defaults, or as a copy when you use Save as in Settings. Personas and characters also have a separate display name that appears in chat; when it matched the item's name, it follows a rename.

Renaming and deleting reach everything that points at the item:

  • Renaming a lore book or regex script updates every persona and character that lists it. Deleting one removes it from those lists.
  • Renaming a character updates the lore entries whose character filter names it.
  • Renaming or deleting a preset repoints or clears every reference to it: in the defaults new chats start from, in open chats and in chats on disk. Chats on disk are rewritten the next time they are saved or opened; if a rewrite fails you are told once and Ashyo keeps trying.
  • Deleting a persona or character switches the chats that used it to User or Assistant.

A persona or character can only list lore books and regex scripts that exist, and the configuration file is checked for that when Ashyo starts.

Connection presets

A connection preset is a named route to a model: the provider and protocol, then only the fields that provider uses, such as address and port, base URL, account, model, extra request fields, OpenRouter's model providers, quantizations and fallback flag, and the context size with its auto-update flag. New presets start as KoboldCPP over text completions. Changing the provider clears the account unless you choose one. Every field is explained in Connections.

Sampler presets

Two tabs, because chat completions and text completions take different samplers. Each preset holds a full set of values for its protocol, shown in groups with their limits. Nothing ships here; Ashyo's built-in defaults apply until you save a preset from Settings or make one. See Samplers.

System prompts

A system prompt has a name and its text, edited in the full-screen editor. It opens the prompt and can use macros such as {{char}} and {{user}}. A chat picks one on the Prompt tab of Settings and can override its text per chat. See System prompt.

Personas and characters

A persona has a Name (what appears in chat), a Description and a list of Lore books. A character has those plus Personality, Scenario, its own System prompt and Post-history instructions with a "prefer" flag for each, Greetings, Example messages and Regex scripts. All of it, including what greetings and example messages do, is in Personas and characters. Character cards in PNG or JSON form import straight into the Characters tab; see Character cards.

Lore books

A lore book has a name and a list of entries. On the Lore books tab the entries list as checkbox rows, each labeled by its comment (or by its keys when it has no comment), with the checkbox showing whether the entry is enabled, followed by a New entry row. While entries are showing, the title changes to "Library — sort ↑" or "↓" to show how they are sorted.

Enter
Toggle the entry on or off.
Tab
The entry's actions: Edit, Duplicate (a copy right below it), Move up and Move down (only while sorted in ascending book order), Move to book and Copy to book (when you have other books; copying confirms with a notice), and Delete.
Alt+S
Cycle the sort: Book order, Comment, Insertion order, Priority. Alt+< and Alt+> set the direction. The same choice lives on the Appearance tab of Settings.
Typing
Filter the entries by comment, keys, secondary keys and content. Move up and Move down are hidden while a filter is active. Switching to another book clears the filter.

Opening an entry shows its fields under the heading "Entry N"; Esc returns to the list with the cursor on that entry. What every field means, from keys and secondary keys to position, sticky and group weight, is in Lore books. World Info files from SillyTavern import as lore books; see World Info.

Regex scripts

A regex script has a name, an on/off switch, a Global flag, a Pattern, a Replacement, Trim strings, what it Applies to, a Mode, Min depth and Max depth, Run on edit and Macros in pattern. A pattern that does not compile is refused when you save it. Everything about writing one is in Regex scripts.
