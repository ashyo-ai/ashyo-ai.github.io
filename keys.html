Keyboard reference

Every key Ashyo understands, grouped by where you are when you press it. Keybindings are fixed and there is no key help inside the app, so this is the page to keep open while you learn. Each box's last line shows the hints that matter right now, such as "enter: open, esc: close", and the mouse wheel scrolls whatever is under the pointer everywhere.

Anywhere in the chat screen

These work whether the composer or the transcript has focus, as long as no box is open. Explained in Focus and global keys.

KeyDoes
Ctrl+↑ / Ctrl+↓Move focus to the transcript or the composer.
EscClear the mark or range; otherwise stop a generation; otherwise, on an empty composer, open the turn tree.
Ctrl+SOpen the chat picker.
Ctrl+POpen the model dock (empty composer).
Alt+HOpen the history dock.
Ctrl+OFold or unfold every reasoning block.
PageUp / PageDownScroll an overflowing composer; else move the mark by a screen; else scroll the transcript.
Ctrl+Home / Ctrl+EndJump the transcript to its top or bottom.
Ctrl+VPaste from the system clipboard.
y, n, EscAnswer the quit question: quit, or keep working.

Composer

Explained in Composer and commands.

KeyDoes
EnterSend; on an empty composer, ask for a reply without a message.
Alt+Enter, Shift+Enter, Ctrl+JInsert a newline.
← / →Move by a character; on an empty, idle chat, swipe the last reply.
Ctrl+← / Ctrl+→, Alt+← / Alt+→Move by a word.
↑ / ↓Move by a wrapped row; on an empty composer, recall older or newer input.
Home / EndStart or end of the line.
Shift + movementExtend the selection.
Ctrl+ASelect all.
Backspace, Ctrl+HDelete the previous character.
Ctrl+Backspace, Alt+BackspaceDelete the previous word, or back to the previous / in a path argument.
DeleteDelete the next character.
Ctrl+Delete, Alt+DeleteDelete the next word.
Ctrl+CCopy the selection.
Ctrl+XCut the selection.
Ctrl+ZUndo.
Ctrl+Shift+Z, Ctrl+RRedo.
EscDismiss a refusal shown above the composer.

Completion, history and model docks

KeyDoes
/ as the first characterOpen the completion dock.
↑ / ↓Move the highlight.
PageUp / PageDownScroll the list.
TabAccept the highlighted command (adding a space when it takes an argument), or put the highlighted history entry in the composer.
EnterAccept and run a command; put a history entry in the composer; set the highlighted model.
EscClose the dock.

Transcript

With the transcript focused. Explained in Marking messages.

KeyDoes
↑ / ↓Move the mark from message to message, or extend a range.
Shift+↑ / Shift+↓Select a range from the mark.
Home / EndScroll to either end, extend the range to it, or move the mark there.
PageUp / PageDownMove the mark by a screen.
Tab / Shift+TabOpen the actions menu for the marked message or range.
DeleteAsk to delete the marked messages.
← / →Swipe the last reply while idle.
/Open the search.
n / NNext or previous search match.
cJump to the "last prompt starts here" marker.
EscClear the range or mark.
mouse drag, releaseSelect text and copy it on release.

Actions menu and other popups

KeyDoes
Tab, ↓Next item, wrapping.
↑Previous item, wrapping.
EnterChoose the item, or submit a one-line field.
EscBack out; from a confirmation, back to the menu on the same item.
Ctrl+Z, Ctrl+Shift+Z or Ctrl+RUndo and redo in a one-line field.

Editing a message in place

KeyDoes
EnterSave the edit.
EscCancel the edit.
everything elseAs in the composer; Tab does nothing.

Search and filter fields

The transcript search, the log viewer's find, and the filter line that appears over a list when you type. Explained in Searching the transcript.

KeyDoes
printable charactersType into the field; in a list, start filtering.
EnterRun the search.
EscCancel the search, or clear the filter.
Ctrl+VPaste into the transcript search.
↑ ↓ PageUp PageDownAlways go to the list behind a filter, not the field.

Filter fields have no undo, so Ctrl+Z, Ctrl+Shift+Z and Ctrl+R do nothing in them.

Boxes in general

Explained in Boxes. Each box adds its own keys below.

KeyDoes
EscStep back: close an open entry, clear a filter or search, then close the box.
Tab / Shift+TabNext or previous tab in a box with a tab strip (turn tree, itemization, log viewer), wrapping and skipping unavailable tabs.
↑ ↓ PageUp PageDown Home EndScroll a read-only pane or move in a list.
Ctrl+ASelect all in a read-only text pane.
Ctrl+C, Ctrl+Shift+CCopy the selection in a text pane and clear it.
mouse wheelActs as ↑ and ↓ unless the box scrolls itself.
mouse dragSelect text in a read-only pane.

Lists and choice lists

Choice lists open from a Settings or Library row; the color scheme list previews as you move. Explained in Using the board.

KeyDoes
↑ / ↓Move the cursor, skipping rows that cannot be chosen.
PageUp / PageDownPage the list.
EnterChoose, toggle a checkbox row, or add from an "add" row.
printable charactersFilter a model or lore book list by label or description.
EscClear the filter first, then cancel.

Chat picker

Explained in The chat picker.

KeyDoes
printable charactersFilter chats by name.
↑ / ↓Move the cursor, skipping the rule between open and saved chats.
EnterOpen the highlighted chat.
TabActions for a saved chat: Details, Rename, Export…, Delete.
Alt+IImport a transcript.
Alt+SCycle the sort key (Name, Created, Modified, Turns, Duration, Size).
Alt+< / Alt+>Sort ascending or descending.
EscClear the filter; otherwise close. In Details, go back.

Turn tree

Explained in The turn tree.

KeyDoes
Tab / Shift+TabSwitch between the All and Active branch views.
↑ ↓ Home End PageUp PageDownMove the cursor.
→ / ←Open or close a fold at a fork.
EnterSwitch to the selected turn's branch; on the root row, restart the chat; on the current leaf, close.
Ctrl+LLabel the selected turn (blank clears).
Ctrl+FFork a new chat from the selected turn.
printable charactersSearch message text and labels; an uppercase word is case-sensitive.
EscClear the search; otherwise close.

Settings and Library

Both share one layout: a list of categories on the left and rows on the right. Explained in Using the board.

KeyDoes
← / →Switch between the category pane and the rows.
↑ / ↓Move in the current pane, skipping headings and categories that do not apply.
PageUp / PageDownPage the rows.
EnterChange the row: flip a checkbox, open a choice list, open a text editor, edit a value in place, or run an action row.
TabOpen the row's actions (Save, Save as, Rename, Delete, Reset and so on).
Alt+SCycle the sort key of a sortable list such as lore entries.
Alt+< / Alt+>Sort ascending or descending.
printable charactersFilter rows where a filter is offered, such as lore entries.
EscClose an open entry; otherwise clear the filter; otherwise close the board.

Editing a value in place

KeyDoes
EnterSave the value after checking it.
EscCancel.
↑ / ↓Step a number by its step size.

Full-screen text editor

Opens from long text rows such as a description or system prompt. Explained in Using the board.

KeyDoes
EnterInsert a newline.
Ctrl+SSave.
EscClose at once if unchanged; otherwise ask Discard and close, Save then close, or Cancel. With text selected, clear the selection first.
Ctrl+ZUndo.
Ctrl+Shift+Z, Ctrl+RRedo.
Home / EndStart or end of the line.
Ctrl+Home / Ctrl+EndStart or end of the text.
PageUp / PageDownMove by a page; with Shift, select.
Shift + movementExtend the selection.
Ctrl+CCopy the selection.
Ctrl+XCut the selection.
mouse click, drag, wheelPlace the cursor, select, scroll.

File dialog

Explained in The file dialog.

Prompt inspector and itemization

Explained in The prompt inspector and Itemization.

KeyDoes
