CLI

One binary, a handful of subcommands, and a print mode for running a single prompt without the TUI.

Synopsis

ashyo                                     open the TUI
ashyo -p PROMPT [--model provider/model]  run one prompt, print the answer
ashyo login [--device] openrouter|openai-codex
ashyo logout openrouter|openai-codex
ashyo session list [--limit N]
ashyo session search QUERY [--limit N]
ashyo session resume SESSION_ID
ashyo session export SESSION_ID
ashyo session delete SESSION_ID
ashyo agent cleanup AGENT_ID [--abandon]
ashyo memory inspect MEMORY_ID
ashyo diagnostics

Print mode

$ ashyo -p 'What does internal/policy export?'
$ ashyo -p --model openrouter/~z-ai/glm-flash-latest 'Reply with exactly OK'
$ ashyo -p -- '--this prompt starts with dashes'
-p, --print
Run the next argument as the prompt. -p=PROMPT and --print=PROMPT work too. Given once only.
--model provider/model
Use one model with no fallback list.
--
Everything after it is prompt text.

Print mode runs on the same runtime as the TUI: same session store, same rules, same tools, same memory. It differs in one way. It is uninterrupted: nothing can prompt you, so an ask decision is treated as allow and the ask_user tool is withdrawn from the model. A deny still denies. Give print mode a rule set you would be comfortable running unattended.

The final answer goes to stdout. Notices, including a degraded memory drain, go to stderr and do not change the exit code. The run is recorded as a session like any other.

Exit codes

CodeMeaning
0Completed.
2A policy denial ended the run.
3Provider failure, including a model reference that could not be resolved and a credential command that failed.
4Interrupted by SIGINT or SIGTERM, or a login cancelled with Ctrl-C.
5Internal error, including every usage error.

The TUI exits 0 on a normal or Ctrl-C quit, 4 on a signal, and 5 on an internal failure.

login and logout

$ ashyo login openai-codex
$ ashyo login --device openai-codex
$ ashyo login openrouter
$ ashyo logout openai-codex

Flags may go before or after the provider. -h prints usage and exits 0. See Providers for what each flow does.

session

list and search print one session per line as tab-separated id, creation time in UTC, title, and directory, up to --limit (default 20). search is full-text over the session index.

$ ashyo session search 'migration' --limit 5

resume opens the TUI bound to the session. export writes the session as JSON to stdout. delete removes it. See Sessions.

agent cleanup

Removes a subagent's worktree and metadata once its work has been integrated. A child with uncommitted changes is always refused. A child whose branch has not been merged is refused unless --abandon is given, which discards the work. See Agents.

memory inspect

Prints one memory record as JSON by id. Ids appear in recall results.

diagnostics

Checks each subsystem and prints one line per subsystem. Exits 5 if any is unhealthy.

$ ashyo diagnostics
config ok
auth ok openai-codex=present openrouter=absent
sessions ok count=12
memory ok application_id=1095977049 schema=3
worktrees ok creating=0 ready=1 failed=0 orphaned=0 dirty_child=0 clean=0 removed=3 abandoned=0

Environment

VariableEffect
XDG_CONFIG_HOMELocation of the global config. Default ~/.config.
XDG_DATA_HOMELocation of credentials, sessions, memory, models, worktree metadata, and the TUI's input history. Default ~/.local/share.
XDG_STATE_HOMELocation of the log file. Default ~/.local/state.
ASHYO_LOG=debugRaise the log level from warn to debug.

Log file

Warnings that would otherwise be lost, such as a provider stream that ended with a truncated body, are appended to ~/.local/state/ashyo/ashyo.log. The file is created 0600 in a 0700 directory and is never truncated. Credentials are redacted before a line is written. A log file that cannot be opened is silently discarded; logging never fails a turn.
